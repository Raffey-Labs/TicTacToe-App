# TACTIX — Tic Tac Toe

## Run locally

On Windows, double-click **`start-server.bat`**. It opens the game at:

`http://localhost:8000`

Keep the server window open while playing. Press `Ctrl + C` in that window to stop it.

Python is the only requirement. If it is not installed, download it from [python.org](https://www.python.org/downloads/).

## Share with a friend

Send the complete folder (or a ZIP containing it), including `start-server.bat`, `index.html`, `styles.css`, and `script.js`. Your friend can extract it and double-click `start-server.bat`.
